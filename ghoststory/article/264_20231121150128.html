【鬼扣應篇】

好多人會在卡陰後問我：「我怎麼被跟上的？」 人隨時會被跟上，真的沒什麼好問的 > > > > > >兩週前< < < < < < 某天早上9:10左右，我在空無一人的健身房男更衣室裡剛洗完澡，站在鏡子前吹頭髮 忽然間，我看見有一雙裸體的腳，只有膝蓋以下的部分，從男更衣室裡那間可以坐著吹頭髮的房間走出來，走向離我兩小區的置物櫃區 幾秒後，那雙腳的上半身單獨從離我一小區的置物櫃區走出來，往浴室的方向走了過去 我繼續吹我的頭髮，看看祂想做什麼 最後，祂頂著半濕的頭髮，趴在男浴室的門框上，看我吹頭髮，但祂這時只有臉部和兩隻只有前臂的手 頭髮吹乾後，我就走回我的置物櫃區準備拿東西離開了 來到門口時，那個男鬼站在門口跟我說：「我要跟你說⋯⋯⋯⋯」 我只給了祂一個意念：「我不想聽。」 我頭也不回的就走了 > > > > > >一週前< < < < < < 那天看見雙腳鬼後，第一次去健身房 又是空無一人的早晨，沒人的空間，真的有很高機會撞鬼 我在走進男更衣室的大門時，就感覺到了那個男鬼留下的陣法 好多天前我跟祂說：「我不想聽。」後，祂就在門口，留下了等待我的陣法 當我再進入這個門口，祂就可以感知我的來到 祂再次出現在門旁，看著我走進更衣，走出去運動 祂也就靜靜的看著我離開，沒有再說什麼 > > > > > >今天< < < < < < 早上我運動完大約9:25左右 當我走向男更衣室，我想起了那雙鬼腳 看起來祂似乎放棄找我了，但我可不是可以隨便招惹的路人 邊走時，我用意念開始找那雙腿，在我走到離男更衣室20公尺左右 我找到祂了，在男更衣室門口旁邊的虛空牆中，我用意識抓住祂的雙腿，用力的把祂往人世拉 我可以聽見祂哀怨的哭喊聲：「不要拉我～～～我要睡覺⋯⋯⋯」 這鬼真的長的很特別 膝蓋以上，沒有形體；肚子部分有一坨比較圓的陰氣 拉到胸線左右的地方時，當我一放手，祂的靈體瞬間以光速彈回了虛空的牆裡 帶著一絲竊笑的我，開心的去洗澡了 自從前幾天想通了一些事後 我更喜歡跟靈界的東西來往了，我有些新的方案等著拿祂們來試 等有機會再跟大家分享我試出什麼
